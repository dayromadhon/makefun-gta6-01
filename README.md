An original open-world crime game set in Solmar Bay, a sun-soaked coastal city built with three.js. Leo Marín is $4,500 in debt to the loan shark Rocco Vane. Dispatcher Ada Kwan has five jobs that pay it off — if Leo can stay ahead of the Solmar Bay police long enough to run them.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network — the game is static files under `game/`.

## What's in the city

- A 5×5 street grid with glass downtown towers, a beach, a marina and palm-lined avenues
- Arcade driving with handbrake drifts, traffic, parked cars to steal, taxis and police interceptors
- A wanted level (0–5 stars): police cars and foot cops chase, ram and bust you
- Five story missions — steal a car, a timed package run, losing the heat at the pier, a night-shift taxi run, and the courier-van score — plus taxi and courier side jobs in free roam
- Combat on foot (fists and a pistol with reload), pedestrians who flee, a HUD with a minimap, start / pause / mission screens, and a save that keeps your cash and progress
- Synthesized WebAudio sound (engine, sirens, gunshots), particles, screen shake and a low-effects mode (`?fx=low`)
