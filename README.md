An original open-world crime game set in Solmar Bay, a sun-soaked coastal city built with three.js. Leo Marin owes $4,500 to loan shark Rocco Vane, and dispatcher Ada Kwan has five jobs that pay it off — if Leo can stay ahead of the Solmar Bay police long enough to run them.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network — the game is static files under `game/`.

## What's in the city

- A 5×5 street grid with glass downtown towers, a beach with umbrellas and a pier, a marina with docks and boats, and palm-lined avenues
- Arcade driving with handbrake drifts, traffic that follows the streets, parked cars to steal, taxis and police interceptors
- A wanted level (0–5 stars): police cruisers chase, ram and bust you; lay low and the heat cools off
- Five story missions — steal a car for Ada, a timed package run from the marina, losing a two-star tail at the South Pier, a three-fare night shift, and the courier-van score — plus taxi and courier side jobs in free roam
- Combat on foot (fists and a pistol with reload), pedestrians who flee, a HUD with a live minimap, start / pause / mission screens, and a save that keeps your cash and progress
- Synthesized WebAudio sound (engine, sirens, gunshots), drift smoke, impact sparks, screen shake and a low-effects mode (`?fx=low`)
