An original open-world crime game in the sun-soaked coastal city of Solmar Bay, built with three.js. Leo Marín owes $4,500 to the loan shark Rocco Vane — drive, steal cars, outrun the Solmar Bay police and run dispatcher Ada Kwan's five jobs to pay it off.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network — the game is static files under `game/`.

## What's in the city

- A 5×5 street grid with downtown towers, a beach, a marina and palm-lined avenues
- Driving with arcade physics, handbrake drifts, traffic, parked cars to steal, taxis and police interceptors
- A wanted level (0–5 stars) with police cars and foot cops that chase, ram and bust you
- Five story missions (steal a car, a timed package run, losing the heat, a night-shift taxi run, the big courier-van score) plus side jobs in free roam
- Combat on foot (fists and a pistol), pedestrians who flee, a HUD with a minimap, start/pause/mission screens, and a save that keeps your cash and progress
